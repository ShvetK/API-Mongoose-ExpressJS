## Getting Started

### Prerequisites

Git needs to be installed on your machine.
The first step is to clone the tutorial repo in your machine using the below command

```
git clone https://github.com/ShvetK/API-Mongoose-ExpressJS.git
```

After install node_modules in your machine using:

```
npm install
```

Start to node application using the following:

```
npm start
```

You need the tools/libraries/software below to run this project on your machine.

- [VS Code](https://code.visualstudio.com/)
- [Node](https://nodejs.org/en/)
- [npm](https://www.npmjs.com/)
- [Express](https://reactjs.org/)
- [Mongoose](https://mongoosejs.com/)
- [MongoDB](https://www.mongodb.com/)
- [MongoDB Atlas](https://www.mongodb.com/atlas)
- [MongoDBCompass](https://www.mongodb.com/products/compass)
- [Nodemon](https://nodemon.io/) (optional)
- [Postman](https://www.postman.com/)
